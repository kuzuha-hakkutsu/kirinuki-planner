Kirinuki Planner

A private planning and analytics tool for clip videos of public live-stream archives.

About

Kirinuki Planner is a private command-line tool used only by its developer. It helps plan clip videos ("kirinuki") of the public live-stream archives of one VTuber, Kuzuha (NIJISANJI). The clip videos are made in accordance with the talent agency ANYCOLOR's official fan-content guidelines.

Kirinuki Planner は、開発者本人だけが使う非公開のコマンドラインツールです。にじさんじ所属 VTuber「葛葉」の公開配信アーカイブから切り抜き動画を企画するために使います。切り抜き動画は ANYCOLOR の二次創作ガイドラインに従って制作します。

How it uses YouTube API Services

  • Lists the public live-stream archives of one channel and their public statistics.
  • Finds third-party clip videos whose descriptions cite those archives.
  • Ranks archives and moments with custom metrics (for example, growth relative to archives of similar age, and how few recent clips exist). These custom metrics are calculated by this tool and are not provided by YouTube.

The tool is not published or distributed, has no user accounts, and does not use Google sign-in (OAuth). It does not download, store, or display YouTube audiovisual content through YouTube API Services.

YouTube API サービスでは、対象チャンネルの公開アーカイブと公開統計、それらを引用している他チャンネルの切り抜き動画を取得し、独自の指標でランキングします。独自の指標はこのツールが計算したもので、YouTube が提供するデータではありません。ツールは公開・配布しておらず、ユーザーアカウントや Google ログインもありません。
