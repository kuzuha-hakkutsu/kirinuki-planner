Privacy Policy

Kirinuki Planner · Effective date: October 16, 2026

1. Use of YouTube API Services

Kirinuki Planner uses YouTube API Services. By using Kirinuki Planner, you are also subject to the Google Privacy Policy.

Kirinuki Planner は YouTube API サービスを使用しています。利用にあたっては Google プライバシーポリシー も適用されます。

2. Who uses this tool

Kirinuki Planner is a private tool used only by its developer. It has no user accounts, does not offer Google sign-in (OAuth), and does not access any Authorized Data. It does not collect personal information from users.

本ツールは開発者本人だけが使う非公開ツールです。ユーザーアカウントや Google ログイン（OAuth）はなく、ユーザーから個人情報を収集しません。

3. Data accessed through YouTube API Services

Using an API key, the tool accesses only public data:

  • Public metadata of public videos (title, description, publish date, duration, live-stream start/end times, privacy status).
  • Public statistics of videos (view, like, and comment counts) and channels (subscriber counts).
  • Public metadata of third-party clip videos. Their descriptions are read only to find which archive they cite and are not stored.

API キーで公開データだけを取得します（公開動画のタイトル・概要欄・公開日・長さ・配信時刻・公開状態、再生数・高評価数・コメント数・登録者数などの公開統計、他チャンネルの切り抜き動画の公開情報）。切り抜き動画の概要欄は、元配信を特定するためだけに読み、保存しません。

4. How the data is used and shared

The data is used only to plan which archives and moments to make clip videos of. It is not sold, shared with third parties, or published. Custom metrics calculated by the tool are labeled as not provided by YouTube.

データは、どの配信・場面を切り抜くかを企画するためだけに使います。販売・第三者提供・公開はしません。

5. Storage and retention

  • Data is stored only on the developer's local computer.
  • Statistics are kept for no longer than the period permitted by the YouTube API Services Developer Policies (30 days by default).
  • Other API data is refreshed or deleted within 30 days.
  • If a channel owner asks us to delete data about their content, we delete it within 7 days.

データは開発者のローカル PC にのみ保存します。統計は YouTube API サービス開発者ポリシーで認められた期間（既定 30 日）を超えて保存しません。その他のデータは 30 日以内に更新または削除します。チャンネル所有者から削除の依頼があれば 7 日以内に削除します。

6. Cookies, advertising, and this website

The tool runs locally and does not use cookies. This website does not use cookies, analytics, or advertising, and no third party serves content or ads on it. The hosting provider may keep standard access logs under its own privacy policy.

ツールはローカルで動作し、Cookie を使いません。このウェブサイトも Cookie・アクセス解析・広告を使いません。ホスティング事業者が自社のポリシーに基づきアクセスログを記録する場合があります。
